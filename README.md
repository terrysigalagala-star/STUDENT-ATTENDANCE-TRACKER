
# Student Attendance Tracker

## Description
The Student Attendance Tracker is a simple system designed to help manage and monitor student attendance. It
makes it easier to record attendance and view attendance reports.

## Features
- Home page dashboard
- Record student attendance
- View attendance reports
- Simple and user-friendly interface

## Technologies Used
- HTML
- CSS

## Installation
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
